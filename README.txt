PORTFÓLIO PESSOAL — MARIAH EDUARDA

COMO ABRIR
1. Extraia portfolio_av2.zip.
2. Abra a pasta portfolio_av2 no VS Code.
3. Abra index.html no navegador (ou use a extensão Live Server).

ESTRUTURA
- index.html: conteúdo do portfólio.
- css/style.css: visual, responsividade e modo claro/escuro.
- js/script.js: menu móvel, saudação, alternância de tema, ano e validação do formulário.
- img/foto-mariah.webp: foto profissional para o perfil.

SEÇÕES
- Início, Sobre mim, Habilidades, Projetos e Contato.
- Contatos clicáveis: e-mail, WhatsApp, Instagram, GitHub e LinkedIn.
- Projeto Up, Sistema de Gestão Escolar e conceito GeoCidadão.

IMPORTANTE
- O formulário valida os dados no navegador, mas não envia mensagens nem armazena dados.
- O terceiro projeto é apresentado como conceito em desenvolvimento. Atualize a descrição para refletir exatamente o que você fez.
- O portfólio exibe seu telefone publicamente. Se não quiser divulgar esse dado, remova o cartão de WhatsApp do index.html.
- Confirme que as habilidades e tecnologias listadas correspondem ao que você estudou e consegue explicar.

DEFESA DA AV2
- HTML organiza o conteúdo e usa elementos semânticos.
- CSS define identidade visual, layout, responsividade e estados de foco.
- JavaScript controla o menu, saudação por horário, tema, ano e validação do formulário.
